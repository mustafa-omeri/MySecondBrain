## Bu dosya ne işe yarar?

`user.md` ve `preferences.md` **senin sözlerinle** dolar — onların
dayanağı senin ifadendir. Bu dosfa ise **dediklerinden çıkan** kalıpları
tutar.

| | |
|---|---|
| `stated` | sen doğrudan söyledin → `user.md` |
| `inferred` | ajan örüntüden çıkardı → **burada** |
| terfi | 3+ gözlem + senin onayın → `preferences.md` |
